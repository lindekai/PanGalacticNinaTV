# Licensing and attribution

## Algorithms

The astronomy engine (`Packages/PanGalacticCore/Sources/PanGalacticCore/Astronomy/`) is own Swift code. Its formulas follow Jean Meeus, *Astronomical Algorithms*, 2nd edition (Willmann-Bell, 1998): Julian day (ch. 7), sidereal time (12), coordinate transformation (13), rising and setting (15), angular separation (17), precession (21), nutation and obliquity (22), Sun (25), Moon (47, main periodic terms), illuminated fraction (48). Formulas and published coefficients are used; no code was copied.

## Reference data in the tests

`Packages/PanGalacticCore/Tests/PanGalacticCoreTests/Fixtures/astronomy/reference.json` was generated by `tools/astronomy/reference_values.py` from the JPL DE421 planetary ephemeris (NASA/JPL, public) with Skyfield 1.55 (MIT licence, used only in that tool, not shipped). Sunset (15:39 UT) and moonrise (13:05 UT) of the first site (`central-europe-november`) were cross-checked against the U.S. Naval Observatory Astronomical Applications API (public). The test sites are invented.
